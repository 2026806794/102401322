1"""中文分词。 

2 

3直接用 jieba 分词在弹幕上效果不好，主要有两个问题： 

4 

5 1. 领域词会被切碎，比如"大语言模型"变成"大/语言/模型"； 

6 2. 弹幕里口语和灌水词太多，"哈哈哈""前排"这些分词出来会占满词频榜。 

7 

8所以这个文件做了三件事： 

9 1. 加载自定义词典（noise_lexicon 里的 JIEBA_USER_WORDS）； 

10 2. 分词后按停用词表过滤； 

11 3. 过滤单字、纯数字、纯符号这些没信息量的 token。 

12 

13另外加了一个分词结果缓存。这是用 cProfile 分析之后加的： 

14统计接口 68% 的时间都花在分词上，而弹幕里有不少重复的句子， 

15缓存一下能省点时间（实测命中率 26.8%）。 

16"""

73 def is_meaningful(self, token): 

74 """判断一个 token 值不值得统计。""" 

75 token = token.strip() 

76 if len(token) < self.min_length: 

77 return False 

78 if token in self.stopwords: 

79 return False 

80 if _meaningless.match(token): 

81 return False 

82 return True

118 def segment_batch(self, texts): 

119 """批量分词。""" 

120 return [self.segment(text) for text in texts]

122 def count_words(self, texts): 

123 """统计词频，返回 {词: 次数}。""" 

124 counter = {} 

125 for text in texts:

134 def top_words(self, counter, top_n=8): 

135 """取词频前 N 个。
