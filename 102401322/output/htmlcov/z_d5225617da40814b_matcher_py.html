1"""多模式匹配（Aho-Corasick 自动机）。 

2 

3为什么需要它：统计"每条弹幕属于哪个领域 / 提到了哪个产品"的时候， 

4最直接的写法是两层循环： 

5 

6 for 每条弹幕: 

7 for 每个类别: 

8 for 每个别名: 

9 if 别名 in 弹幕: 计数 + 1 

10 

11我的词典有 433 个别名，弹幕有 6 万多条，这样算下来要几秒钟。 

12所以换成了 AC 自动机：把所有别名建成一棵树，一次扫描就能同时找出所有命中的词。 

13 

14原理（数据结构课上学过，这里自己实现了一遍）： 

15 1. 建 Trie：把所有模式串插到一棵树上，每个节点是一个字符； 

16 2. 补失败指针：用 BFS 遍历，每个节点的 fail 指向"最长后缀"所在的节点。 

17 这样匹配时如果当前字符走不通，就顺着 fail 跳，不用从头重新匹配； 

18 3. 合并输出：把 fail 节点上的输出也并到当前节点，匹配时就不用顺着 fail 链 

19 一个个找了。 

20 

21复杂度从 O(文本长度 × 模式数) 降到 O(文本长度 + 命中数)。 

22实测（3000 条弹幕、433 个模式）比朴素写法快 12.5 倍左右。 

23"""

47 def _insert(self, pattern, label): 

48 """把一个模式插到 Trie 里。""" 

49 node = 0 

50 for char in pattern: 

51 if char not in self.children[node]: 

52 # 需要新建节点 

53 self.children.append({}) 

54 self.fail.append(0) 

55 self.outputs.append([]) 

56 self.children[node][char] = len(self.children) - 1 

57 node = self.children[node][char]

63 def _build_fail(self): 

64 """用 BFS 建失败指针。 

65 

66 根节点的直接子节点 fail 都指向根。其他节点：假设父节点是 p，当前字符是 c， 

67 就沿着 p 的 fail 往上找，看哪个祖先有 c 这个子节点，那个子节点就是当前节点的 fail。 

68 """ 

69 queue = [] 

70 # 第一层：fail 都指向根 

71 for char in self.children[0]: 

72 child = self.children[0][char] 

73 self.fail[child] = 0 

74 queue.append(child) 

75 

76 head = 0 

77 while head < len(queue): 

78 node = queue[head] 

79 head += 1 

80 

81 for char, child in self.children[node].items(): 

82 # 从父节点的 fail 开始往上找 

83 fallback = self.fail[node] 

84 while fallback and char not in self.children[fallback]: 

85 fallback = self.fail[fallback] 

86 if char in self.children[fallback]: 

87 self.fail[child] = self.children[fallback][char] 

88 else: 

89 self.fail[child] = 0 

90 

91 # 把 fail 节点的输出合并过来，匹配时就不用再顺着 fail 链找了 

92 for label in self.outputs[self.fail[child]]: 

93 if label not in self.outputs[child]: 

94 self.outputs[child].append(label) 

95 

96 queue.append(child)

98 def find_labels(self, text): 

99 """找出文本里命中了哪些标签（去重）。""" 

100 labels = set() 

101 node = 0 

102 for char in text: 

103 # 走不通就顺着 fail 跳 

104 while node and char not in self.children[node]: 

105 node = self.fail[node] 

106 node = self.children[node].get(char, 0) 

107 if self.outputs[node]: 

108 labels.update(self.outputs[node]) 

109 return labels
